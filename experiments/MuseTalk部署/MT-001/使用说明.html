MuseTalk 实例使用说明

部署目录：/root/autodl-tmp/avatar-musetalk/MT-001。 当前部署已经用四条短视频验证推理；完整视听、长视频和生产服务尚未验收。

进入环境

SSH 登录后执行：

source /root/miniconda3/etc/profile.d/conda.sh
conda activate /root/autodl-tmp/avatar-musetalk/MT-001/env
cd /root/autodl-tmp/avatar-musetalk/MT-001/source
export OMP_NUM_THREADS=8 MKL_NUM_THREADS=8
export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1
export TORCH_HOME=/root/autodl-tmp/avatar-musetalk/MT-001/torch-cache

可用入口

  • 单图或普通视频推理：python -m scripts.inference_mt001。这是官方入口的临时目录保护版。
  • 下一次实时/缓存任务：python -m scripts.realtime_inference_mt001_fixed。这是计时版加末帧修复，7 项离线回归测试通过；修复后的真实出片尚待下一任务复核。
  • 所有入口显式传入 --unet_model_path models/musetalkV15/unet.pth --unet_config models/musetalkV15/musetalk.json --version v15 --fps 25 --batch_size 4。
  • 普通模式另加 --use_float16；官方实时模式内部使用半精度，不接受同名开关。

新任务先创建独立 YAML 和输出名，再传 --inference_config。 普通模式设置独立 --result_dir；实时模式实际在 results/v15/avatars/<avatar_id> 保存缓存及视频，不能仅依赖 --result_dir 隔离。 同一母版缓存存在时使用 preparation: false，音频条目的键是输出文件名，必须换新名字以免覆盖已有原片。 新母版或改变裁剪、遮罩、模型、服装/背景时使用新的 avatar_id，重新准备，不删除旧缓存来覆盖证据。

本轮材料的位置

  • 原图、原 WAV、阿里原片及两个明确派生素材：source/inputs/。
  • 单图原片：source/results/MT001-M1/v15/M1_original.mp4。
  • 动作母版原片：source/results/v15/avatars/mt001_motion_v1/vid_output/。
  • 环境版本：environment.lock.txt。
  • 权重及素材摘要：weights-manifest.json、inputs-manifest.json。
  • 运行日志和显存采样：logs/。

本轮 run-M1.sh、run-M234.sh 有执行标记；不要删除标记或复跑覆盖原始试验。 已有四条原片保留官方实时路径的末帧问题，不能将其视为修复版的验证结果。 本机可播放对比页为 样片对比.html；详细记录在 部署与首测结果。

实例费用

用户提供单价 1.58 元/小时。模型进程已结束，实例仍然开机。 不用时在算力云控制台关机；退出 SSH 或停止 Python 不会自动关闭平台计费。 环境和权重保留在数据盘，保留期限、付费磁盘和重新开机可用性以平台规则为准。 此部署没有开放公网 Web/API 服务，也没有自动关机或抖音发布任务。
