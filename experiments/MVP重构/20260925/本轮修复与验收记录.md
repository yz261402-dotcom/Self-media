## 本轮实际修复

- 前端重组为七入口与常驻五步向导，显示当前作品、已选内容、缺项和下一步。人物使用真实图片卡片，复杂审核和历史记录折叠展示；窄屏改为顶部滑动导航，正文全宽。
- 修复切换作品、A→B→A、旧任务迟到、音频返回及后期轮询覆盖当前作品的问题；下载包另行核对作品归属。
- 冻结但缺审核资料的人物可以“复制为新草稿”：原图复用，建立独立待审核身份和许可；不修改原人物、资产、作品，不自动通过审核。
- 修复音频有文件但没有播放 URL 的问题：接口核验本地文件哈希后返回媒体地址，兼容上传后仍保留本地副本的历史音频。Mock 和缺失/篡改文件不给播放地址。
- 统一 Provider 配置，修复结构化响应、错误脱敏、TTS 幂等与租约；同输入优先复用有效全文音频，只有显式重做才提交新合成。
- 生产工作项默认实际进入 DeepAgents 图执行受控工具；总控保持依赖、人工选择门与持久记录。每个工具前、阶段结束后校验取消/任务替换。默认决策为 deterministic，正文仍可调用真实 DeepSeek；全模型自主调度未验收且其可选依赖当前未安装。
- 后期执行放到工作线程：当前原片 + 当前音轨 + 真实字幕时间轴 → FFmpeg 规格、响度、字幕和封面 → 技术复验。没有 editor Agent，也没有恢复联网写稿。
- 成片确认携执行版本；真实 ZIP 包含视频、ASS/SRT、封面、文案、质量报告和 manifest。取消、任务替换、输入变化、审核撤销、文件缺失/哈希变化会阻止旧结果交付。重复打包幂等并串行保护。
- 启动脚本支持自定义端口、日志、健康检查、冲突检查与服务复用。启动只会复用已健康服务；代码更新后的后端需要重启。

1. **最终后端：950 passed，1 个既有 Starlette 弃用警告，187.82 秒。** 见 [最终回归日志](最终后端回归-通过复验.log)。使用独立数据库与 D 盘临时目录，不对正式库运行测试。前一轮 947 passed / 1 failed 的日志保留；失败来自可选 `langchain-openai` 的标注遗漏，修复后全量重新通过。
2. **前端：24/24，typecheck 与 build 通过。** 覆盖作品恢复、跨作品隔离、旧任务/媒体迟到、人工试听确认、人物修复入口、下载就绪等关键交互。
3. **真实本地后期：** 复用已有 M2 原片、TTS 与既有 Qwen 时间轴，输出 23.166667 秒、1080×1920、30 fps、H.264 / AAC；响度 −14.55 LUFS、峰值 −2.49 dBTP，完整解码及黑帧/冻结粗筛通过。本次处理耗时 33.658 秒，视频 5,037,302 字节；证据在 [真实后期验收](真实后期验收/验收证据.json)。这些结果不等于人工口型或身份审核通过。
4. **浏览器真实交互：** 隔离库创建作品，刷新恢复同一作品；离线三稿展示与采用；复制角色打开独立四步审核；真实音频加载并播放（23.186719 秒），工程夹具仍不能被确认成生产音频；七入口可达。
5. **播放器与下载组件：** 状态使用明确标识的浏览器路由夹具，播放字节来自本地真实成片；确认请求包含当前 execution_id，未勾选不能确认。工程样包经浏览器下载，5,173,614 字节，SHA256 与源包一致，ZIP 校验正常。此项没有向正式后台写入人工审核，不能当作全链路生产验收。见 [重复验证脚本](播放器与下载界面验收.js)、[界面证据](浏览器验收证据.json)。
6. **视觉检查：** 1440px 桌面与 390px 手机截图复验。曾发现固定侧栏挤压手机正文，已改为顶部导航；最终页面无新增控制台错误。截图：[桌面](人物与制作向导.png)、[手机](手机制作向导.png)、[成片组件夹具](成片播放器与下载-工程夹具.png)。
