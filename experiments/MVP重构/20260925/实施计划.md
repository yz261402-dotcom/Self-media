# MVP 可用性修复与前端重构实施计划

**目标：** 按已批准 v2.4 方案，让单用户从作品创建沿明确步骤完成真实制作、预览和下载。保留七入口，前四项为 MVP。任何外部条件不足都显示可操作原因。

**架构：** Vue 3 创作向导；FastAPI 聚合接口；content、quality、avatar、audio 四类智能体；媒体与字幕后期由代码 Worker 执行。延续已实现 Provider、固定身份及音频版本约束。

**技术栈：** Vue 3 / Pinia / TypeScript / FastAPI / SQLite / DeepAgents / FFmpeg / Qwen ASR + ForcedAligner / 既有模型适配器。

## 根因与执行顺序

- [x] 核查方案、运行环境、前端和后端现状；禁止读取 demo。
- [x] 保存修改前源码快照，保留运行库与历史实验。
- [x] 前端：修复切作品/刷新状态污染，新增制作向导、明确下一步、音频试听、完成后下载。
- [x] 生成：修复供应商配置分歧、响应边界、脱敏错误；按新旧稿件绑定输入。
- [x] 后期：修复 FFmpeg 查找、当前音视频绑定、字幕缓存与异常处理；保留执行证据。
- [x] 串联：提供异步后期入口、可追溯发布就绪包、真实下载；失败可重新触发本地处理。
- [x] 启动：统一启动目录、健康检查、后台日志，避免重复端口与固定休眠猜测。
- [x] 工程验证：关键行为先写失败测试；独立数据库后端 950 项通过；前端 24 项、类型与构建通过；浏览器分段交互、真实媒体后处理独立实测。
- [x] 更新使用说明与已验证/未验证清单。
- [ ] 外部完整验收：恢复算力云后，以新稿、新音频、新生成口播跑一次真实生产闭环；补用户实际人物/口型观感审核。此项未冒用离线或工程夹具结果。

## 验收边界

1. 页面明确显示当前作品、当前步骤、已选人物/稿件/音频、下一步条件；刷新可恢复，切作品不串数据。
2. 缺密钥、音频未确认、原片未审核、GPU 未连通时显示真实阻断，不拿 mock 宣称完成。
3. 最终交付有真实 MP4、字幕、封面与元数据；下载校验文件存在、哈希和输入版本。
4. 验证区分离线契约、真实本地后期、真实外部生成；本轮不擅自提交新增收费生成测试。
5. 不重做已确定的产品设计，不删除历史证据；改动聚焦首版可用性。

## 验证命令

后端：`production/backend/.venv/Scripts/python.exe -m pytest production/backend/tests -q --tb=short`。

前端：在 `production/frontend` 运行 `npm run typecheck`、`npm run build` 和本次新增的状态逻辑测试。

浏览器：启动独立端口，检查新建、选人物、选稿、试听、确认、视频条件和下载；有计费副作用的操作仅在获得对应预算时实测。
