## 1. 实施边界与门槛

1. 本轮只生成文档，以下文件路径是后续拟创建目标，不代表已经存在。
2. 先在隔离环境完成已选模型接入、所需素材与长片质量验证，再细化对应模块实施；
   工程基础栈也须另行选型，之后才能投入完整 UI 和批量生产；
   结构性 Mock 流程不能代替该门槛。
3. `demo/` 是排除目录，原位保留，不读取、不借鉴、不复制，也不当作负例来源。
4. 新建 `production/` 工程与 `avatar_studio` 包；代码、依赖清单、配置、Schema、
   人物、音色、内容历史和测试全新建立。没有旧系统兼容、适配、数据导入任务。
5. 当前没有 Git 仓库；不自动提交、移动或清理旧目录。开始代码实施时先建立用户选择的版本管理。
6. 真实调用需明确服务、次数、金额和输出目录；本计划不授予支出或真实发布授权。
7. 无权限的官方发布入口必须禁用；先开发发布包和人工回填，符合用户已确认的 V1 范围。

## 3. 阶段、依赖与验收层级

| 门槛 | 任务 | 退出条件 |
|---|---|---|
| G0 文档基线 | 本目录文档 | 需求、契约、方案、计划与验收口径一致 |
| G0→G1 逐环节选型 | 先完成本轮口播 PoC | 候选对比、实际样片、费用、结论与适用范围有证据 |
| 选型后的模块实施 | 对应的 T01～T13，逐项重写 | 该模块选型已定、方案已回填、任务命令与实际栈一致 |
| G1 真人可行性 | T03～T05 | 真人身份、声音、至少一条真实音频驱动样片通过 |
| G2 V1 闭环 | T06～T12 | 真实 RAG 内容生产、视频质检、发布包和人工回填通过 |
| G3 自动发布 | T13 | 官方能力实证及一次真实排期发布独立通过 |

G1 的短样片不能代替 G2 的 60～75 秒完整样片；长期稳定性还需试运营统计。
G0→G1 期间的 Mock 测试不计入“真实视频生产成功率”。

可并行：T03 的图片资产与 T04 的声音；T06 内容检索与 T07 媒体时间线；
G1 通过且契约冻结后，T10 工作台可与 T06～T09 并行。
T05 依赖身份与声音，T09 必须等视频门禁。

不估造精确交付日期。代码任务按可独立验证的增量执行，供应商准入、真实调用等待和人工评审单列；
正式排期至少保留 20% 缓冲，时间承诺须在 G1 真实试验后制定。

## 5. 从零建设约束与设计来源

本项目的设计输入仅为用户需求、已确认范围，以及调研中具有独立来源的厂商能力和平台规则。
调研里针对失败项目的源码结构、接口命名、修补清单、配置和测试结果均不作为实现输入。

- **代码**：各模块独立实现。不得复制旧函数、继承旧类、添加旧包路径或调用旧项目脚本。
- **契约**：按本文关联的新契约设计，不保留失败项目接口和错误语义的兼容义务。
- **数据**：从空状态库开始；新项目的内容历史在新生产过程中积累，冷启动按 PRD 处理。
- **资产**：重新创建并批准 Base Avatar、参考集、变体与 VoiceAsset，不导入旧头像、声音或成片。
- **依赖**：按目标平台与公开文档创建依赖清单和锁文件；独立验证版本、权重许可及服务能力。
- **测试**：需求驱动的新测试、独立 Mock、新造正负例；失败项目的通过报告不能计入验收。
- **媒体**：新写时间线、处理与字幕逻辑；FFmpeg 等通用工具按公开接口使用，不移植旧命令封装。
- **发布**：按所获官方能力新写 Adapter；发布就绪、人工报告、官方回执分别验证。
- **交付**：给出空环境安装与运行证据。全部源码、配置和素材依赖可以在新工程清单中追溯。

新项目建立并验收通过后的自身资产允许长期使用，符合固定主播目标；
“从零建设”约束针对失败项目，不要求每条新视频重新造人或重新设计声音。

## 6. 首次付费试验记录模板

每次真实验证单独登记，全部栏位明确后才允许调用。下表空白项表示未授权，不是可自行补齐的额度。

| 项目 | 必须填写的内容 |
|---|---|
| 试验目标 | 人物、声音、短口播或完整 RAG；只选择本次要验证的问题 |
| Provider 与账号 | 具体服务/模型/地域及已验证能力，不记录明文密钥 |
| 输入 | 主播与音色版本、文件 SHA-256、实际音频时长 |
| 预算授权 | 金额上限、最多提交次数、有效期、授权人；未填写则禁止付费 |
| 重试规则 | 单次提交；结果未知仅查询，不自动重发或跨供应商重试 |
| 输出 | 新 run_id 目录，保存脱敏请求、原始回执、资产、质量报告和账单 |
| 成功标准 | 对应验收编号和人工视听结论；技术完成不代替业务达标 |
| 失败结果 | 真实失败原因、已知/未知计费、下一步；保留全部原始证据 |

生产预算可以后续设为明确额度内自动执行；不应把开发阶段的一次试验授权扩大为无限生产。
