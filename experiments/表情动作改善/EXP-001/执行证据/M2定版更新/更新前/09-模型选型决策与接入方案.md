### 3.2 适配器的具体边界

官方 GPT Image 2 文档支持 Image API 的生成与编辑。[I1][I2] 优先验证中转是否兼容 `/v1/images/generations` 与 `/v1/images/edits`，分别测试人物新建和带固定参考图的编辑。2026-09-22 实测生成接口已经返回两张可解码 PNG；参考图编辑仍未验证，不能因生图成功而标记编辑链路已通过。

配置拆开 `provider=openai_compatible_relay`、`requested_model=gpt-image-2`、`base_url`、`protocol` 和凭据引用。协议尚未实测前保持未验证；若中转仅提供自有封装或 Responses 工具路径，按其真实文档新增协议适配，不静默降级或换模型。

如采用官方兼容 Image API，固定单次候选数量和预算；输出解析基于真实响应，保留原始图片、回执、提示词、参考图哈希及计费用量。官方 GPT 图像路线常返回 Base64，不能假定一定得到图片 URL。

官方资料同时列出 `gpt-image-2-2026-04-21` 快照，当前用户指定的是 `gpt-image-2`，不自行换快照；要记录中转实际返回的模型字段及其可验证范围。参考文档部分通用枚举未及时列出 Image 2，而模型页和指南明确列出它，适配以模型专属说明及实际协议为准。[I1][I2][I3]

### 3.3 固定身份与尺寸

换装/背景必须发送批准的 Base Avatar 作为图像参考，不能只重复同一文本提示词。保留五官、脸型、发型、肤色、年龄、人体比例的约束，对每个变体做身份复核。参考图编辑依然可能漂移，不能承诺像素锁定。

官方 Image 2 的灵活尺寸要求宽高可被 16 整除；`1080` 不满足该条件，不能直接把最终成片尺寸 `1080×1920` 当作合法生图请求。可准备 **1152×2048（9:16）**作为待测尺寸，最终由媒体步骤输出 1080×1920；实际中转尺寸支持须验证。避免为了凑尺寸裁掉头部或双肩。[I3]

## 4. MiniMax Speech 2.8 HD 官方 TTS

- 模型准确拼写：`speech-2.8-hd`；用户提到的“minmax”按 MiniMax 产品归一化，保留 HD 档，不改为 Turbo。
- 官方同步语音接口采用 `POST /v1/t2a_v2`，官方接入域名及字段见 [文本与语音核验](../selection/02-已选模型/官方文本与语音接口核验.md)。生产配置独立于百炼和 GPT 中转。
- 输入：已批准稿件的朗读表达、固定 `voice_setting.voice_id`、经过实测的语速/音调/音量/情绪设置、输出格式。
- 固定音色：用户已选音色 3“温暖闺蜜”，`voice_id=Chinese (Mandarin)_Warm_Bestie`，声音档案 ID 为 `voice_minimax_warm_bestie_v1`；基准参数为 speed=1、vol=1、pitch=0、emotion=calm。原 Qwen 的 `Cherry` 不作为 MiniMax 音色 ID。
- 输出：真实音频文件、实际采样率/声道/时长、用量与响应 ID；有返回字幕文件时同时保存并检查。可先统一请求 WAV，再检测是否直接满足 MuseTalk 解码输入；不满足时生成可追踪的音频格式派生版本。
- 朗读表达：按 MiniMax 已核文档编译停顿标记与参数，不向接口提交任意 SSML；情绪指令、缩写 RAG/API、数字、多音字和跨段连续性逐项实测。
- 字幕：文档有 `subtitle_type=word` 能力说明，返回字幕描述也出现句级说明；这项冲突通过真实样本确定。即使有时间戳，也须与最终音轨核验，不直接宣布字幕模块无需测试。

官方 TTS 成功出声后，还要完成固定声音的多稿件验收。若声音创建、克隆或设计涉及独立接口和费用，作为新的资产任务记录，不由选择 Speech 2.8 HD 自动推定已注册专属声音。
