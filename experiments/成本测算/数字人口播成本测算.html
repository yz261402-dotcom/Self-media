什么时候值得买硬件

按需租 GPU 不要再加一遍显卡折旧和电费。自购成本则按整机购买、残值、使用寿命、电费和维护计算；若机器已有，现金增量成本可能主要是电费，但经济成本仍包括损耗与占用。

当前需求更适合先租云 GPU、批量做完即关机。持续高利用率、画质通过、机器报价与实际吞吐已确认后，再评估采购。

计算公式与容易漏掉的成本
月合格条数 = 每天条数 × 生产天数
API 月费 = 合格条数 × 单条分钟数 ÷ API 付费尝试合格率 × 单价 + 额外月费
预计 GPU 占机小时 = 尝试条数 × 每条视频秒数 × 实测时间比 ÷ 3600 + 每日额外预算 × 生产天数 ÷ 60
按需云月费 = 计划开机小时 × 租金 + 云额外月费（超出容量时标记预算不足）
全天云月费 = 720 小时 × 租金 + 云额外月费（此处按 30 天账期）
自购月成本 = (购买价 − 残值) ÷ 摊销月数 + 计划开机小时 × 平均整机 kW × 电价 + 额外月费

尚需补齐：动作母版创建/更新、TTS 与内容模型、字幕、存储/传输、安装调试、人工质检、运维、质量不合格重做。若这些环节占用同一 GPU，也必须计入实际开机时长。多设备多租金不能只算一张卡。

动作母版可复用，但每套服装/背景可能要重建；费用按实际复用次数摊销。如果每条视频都先调用 API 生成整段母版，再用 MuseTalk 重驱动，并不能省掉整条 API 费用。

质量是前提：MuseTalk 单图头部/眼睛基本静止；缓存样片动作来自阿里母版。60 秒以上的自然动作、循环接缝和稳定合格率尚未验证。短片线性推算只是预算情景，不能把 0.06～0.28 元的活跃时费当成“同等质量的一分钟成片价格”。

现有短片速度证据

单图 M1：9.36 秒输出，整个进程 99 秒。线性到 60 秒输出约 634.62 秒，即 10.58 分钟；活跃时费约 0.27853 元。

动作母版缓存 M3：9.36 秒音轨，同进程缓存调用 22.840906 秒。线性到 60 秒约 146.42 秒，即 2.44 分钟；活跃时费约 0.06426 元。不含启动和母版准备，原样片视频轨有一帧遗漏，不能把这项性能与完整单图流程等同。
