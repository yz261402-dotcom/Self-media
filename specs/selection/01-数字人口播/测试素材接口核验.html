本轮选型试验 / 测试素材接口核验

本轮临时测试素材：百炼图片与标准音色 TTS 接口核验

2026-09-21 核验记录8 个章节Markdown 原文

核验日期：2026-09-21。方法：使用 agent-reach 的 Exa 官方站内搜索与全文读取，交叉核对 API、模型价格和系统音色列表。本文是只读资料核验，未调用收费接口、未读凭据、未生成素材。

本轮用户已授权上限 60 元，包含一张新图、一段 TTS、一次图片检测及两家各一次不超过 15 秒的 720P 视频；各生成请求一次，不自动重试。本文仅为主控准备临时测试标尺，不构成正式产品技术栈选型，也不另行要求用户重复授权。

1. 收敛结果

  • 图片：qwen-image-2.0，北京，同步文生图，一次生成 n=1，合法自定义尺寸 1080*1920，输出 PNG URL。官方单价 0.2 元 / 成功图片。[M1][M2]
  • 音频：qwen3-tts-flash，北京，同步、非流式语音合成，官方系统女声 Cherry（芊悦），一次请求返回完整 WAV URL。官方单价 0.8 元 / 万输入字符，输出不计费。[M3][M4][M5][M2]
  • 两条路径均直接使用文本，不需要声音克隆、音色设计、上传声音训练或生成专属音色 ID。Cherry 是服务自带可调用的系统音色，用于本轮临时测试；不将其描述为某个真人的授权克隆声。[M5]

2. 文生图：精确请求

当前专用 API 推荐北京业务空间域名：[M1]

POST https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation
Authorization: Bearer <北京百炼通用API_KEY>
Content-Type: application/json

这是同步接口，不添加 X-DashScope-Async: enable，不走 /text2image/image-synthesis 的异步体格式。同页明确北京旧域名 https://dashscope.aliyuncs.com“现有域名仍可正常使用”；因此如果主控仅掌握北京 Key，图片调用也有第一方明确支持的旧域名路径。选择一个域名完成本轮唯一提交，不在失败后自动切域名重试。[M1]

可执行请求体（提示词可在唯一调用前由主控冻结）：

{
  "model": "qwen-image-2.0",
  "input": {
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "text": "写实摄影风格，虚构的三十岁中国女性知识分享主持人，单人正面半身肖像，直视镜头，头部端正，眼睛睁开，嘴唇自然闭合，面部完整清晰，真实自然的皮肤纹理。身穿简洁的浅米色圆领上衣，头发整洁且不遮挡眼睛、嘴唇和脸颊。人物位于画面中央，头顶和双肩完整入镜，双手在画面外，纯净柔和的浅灰色背景，均匀柔和的正面摄影棚光线。竖版构图，没有文字、标志或其他人物。"
          }
        ]
      }
    ]
  },
  "parameters": {
    "size": "1080*1920",
    "n": 1,
    "prompt_extend": false,
    "watermark": false,
    "negative_prompt": "多人，侧脸，闭眼，张嘴，遮挡面部，手掌挡脸，裁切头部，墨镜，文字，标志，卡通，塑料皮肤，面部畸形，模糊"
  }
}

选择 prompt_extend=false 是为冻结本轮输入提示词；不是官方必填。watermark=false 是 API 支持的默认选项。正向提示词只允许一个 text，2.0 系列最大 1300 Token；反向提示词最长 500 字符。n=1 避免一次返回多张。[M1]

尺寸依据：2.0 系列支持自由宽高，输出总像素在 512×512 至 2048×2048 之间。1080×1920=2,073,600 像素，位于 [262,144, 4,194,304] 范围，属于合法自定义尺寸。它也满足已核实 S2V 的宽、高各 400～7000 像素。必须检查实际 PNG 尺寸，不能仅凭请求值宣称服务正确返回。[M1]

注意：qwen-image-plus / qwen-image-max 的尺寸是固定枚举，其中竖图为 928*1664；不能把 1080*1920 请求直接换到 Plus / Max。此次不自动换模型。

3. 文生图：响应与取图

以下为依据官网结构整理的示意响应，尺寸展示期望值，不是真实生成证据：

{
  "output": {
    "choices": [
      {
        "finish_reason": "stop",
        "message": {
          "role": "assistant",
          "content": [
            {
              "image": "<生成PNG的完整签名URL>"
            }
          ]
        }
      }
    ]
  },
  "usage": {
    "image_count": 1,
    "width": 1080,
    "height": 1920
  },
  "request_id": "<请求ID>"
}

取图时遍历 output.choices[0].message.content 找 image；验证本轮恰好一张。图片 URL 有效 24 小时，及时保存原始 PNG，记录 SHA-256。同步调用不返回用于轮询的任务 ID，不需要查任务。[M1]

官网失败结构示例为顶层 request_id、code、message，如 InvalidParameter / n must be 1。保留 HTTP 状态和原始 JSON；若超时或缺图，记录本轮失败，不自动重新提交。生成的图能被解码不等于图像检测通过，仍按已授权步骤调用一次 S2V detect。

4. TTS：精确请求

TTS 专用 API 当前北京文档使用以下地址，与图片专页的首选业务空间域名写法不同，按已核实的 TTS 文档执行：[M3]

POST https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation
Authorization: Bearer <北京百炼通用API_KEY>
Content-Type: application/json

非流式 HTTP 请求不带 X-DashScope-SSE: enable，也不带异步头；无需 WebSocket。可执行体形态：

{
  "model": "qwen3-tts-flash",
  "input": {
    "text": "大家好，欢迎收看本期分享。今天聊聊人工智能：先看事实，再做判断。把复杂问题讲清楚，让每次选择更有依据。",
    "voice": "Cherry",
    "language_type": "Chinese"
  }
}

这段文字是临时示例，主控应在唯一调用前冻结实际朗读稿。为减少缩写发音歧义，可把“AI”改为“人工智能”、“API”改为“接口”、“A/B”改为“两组对照”；此处不是语音模型保证的读音控制。官方建议单语输入明确设置 Chinese；混合语种可用 Auto，但文档指出无法保证完全精准。[M3]

text / voice 必填，language_type 可选。此 Qwen3 版本属于 API 文档所述 600 字符上限的非 Qwen-TTS 老系列。标准 qwen3-tts-flash 不需要 / 不支持本轮使用声音设计或克隆；不增加 instructions、speed、duration 等未为此模型核实的字段。[M3][M4]

时长不是请求参数：这个接口不能保证指定稿件生成恰好 15 秒。下载后需探测实际时长，确保本轮给两家的是同一份不超过 15 秒的冻结文件；如需本地调整，保留原始 WAV 和调整记录，禁止只给其中一家不同内容。若素材无法满足测试前提，不能通过再次收费合成绕过“一次、不重试”的本轮限制。

5. TTS：响应与取音频

官网“返回对象”示例包括如下字段；以下保留结构，数值 195 为官网示例用量，不是上方稿件的预测字符数或本轮结果：[M3]

{
  "status_code": 200,
  "request_id": "<请求ID>",
  "code": "",
  "message": "",
  "output": {
    "text": null,
    "finish_reason": "stop",
    "choices": null,
    "audio": {
      "data": "",
      "url": "<完整wav签名URL>",
      "id": "<音频ID>",
      "expires_at": 1766113409
    }
  },
  "usage": {
    "input_tokens": 0,
    "output_tokens": 0,
    "characters": 195
  }
}
  • 下载字段：output.audio.url，完整 WAV 文件，有效 24 小时；expires_at 是 UNIX 时间戳。[M3]
  • 非流式模式的 audio.data 可以为空，不能因为它为空就判失败；完整音频使用 URL 下载。
  • 不需要第二次模型请求取音频，也没有异步任务轮询；下载 URL 是文件获取。
  • 官网返回对象混用 SDK 包装说明，runner 应以真实 HTTP 状态为准，不要求 HTTP JSON 必定包含 SDK 式 status_code。同时保留实际返回 JSON，而不是将文档示例写成结果。
  • 保存原始 WAV，探测容器 / 编码、采样率、声道、时长、文件大小，听辨头尾和缩写读法；不凭 URL 后缀或接口成功状态单独宣称有效。
  • 原始签名 URL 有访问能力，不在公开报告中展示完整 query；本地原始证据按本轮隔离目录保存。

6. 本轮两份临时素材的价格口径

官方北京原价：[M2][M4]

图片费用 = 0.2 元 × 成功生成图片张数
TTS费用 = 0.8 元 × usage.characters / 10000
两份素材直接费用 = 0.2 + 0.00008 × TTS计费字符数

若最终计费为 100 字符，一张图加一段音频的标价估算是 0.2 + 0.008 = 0.208 元。这是条件式估算，未扣免费额度 / 活动优惠，不包含图片检测和两家视频生成。不能用它代替整轮 60 元预算台账。

图片按成功输出张数收费，与分辨率 / 宽高比无关；图片请求失败不收费且不消耗免费额度。TTS 按输入字符计费、输出不计费，真实用量读取 usage.characters。本次查到的 Qwen3-TTS 页面未细化所有标点 / 空白字符计量、最小收费 / 舍入及各种失败状态扣费规则，不能把 Python len(text) 当成已核实账单值，也不套用其他语音产品的字符权重。

文生图价格页列 100 张新人额度，TTS 列 1 万字符额度，均与开通后的有效期有关。账户实际剩余额度未知，本轮按原价保守记录；不会因文档列有免费额度就假定实际免费。

7. 第一方证据

  • [M1] 千问文生图 API，Exa 全文。短引文：“千问图像模型支持同步接口，一次请求即可获得结果”；“输出图像总像素需在512512至20482048之间”；“现有域名仍可正常使用”。字段依据：input.messages、parameters.size/n、output.choices[].message.content[].image、PNG / 24 小时。
  • [M2] 模型调用价格，同日已取得全文，在“千问文生图”和“千问3-TTS-Flash”章节定位。短引文：qwen-image-2.0“0.2元/张”；qwen3-tts-flash“0.8元”每万字符；“按输入文本的字符数计费，输出不计费”。
  • [M3] 非实时语音合成 Qwen-TTS API，Exa 全文。短引文：“完整音频文件的 URL，有效期24小时”；“千问3-TTS-Flash模型返回字符消耗信息”；官方非流式 HTTP 示例使用 model=qwen3-tts-flash、voice=Cherry、language_type=Chinese。
  • [M4] qwen3-tts-flash 模型信息，Exa 全文。短引文：“该模型版本功能等同于快照模型qwen3-tts-flash-2025-11-27”；北京“0.8”元 / 每万字符。
  • [M5] Qwen-TTS 系统音色列表，Exa 全文，定位非实时音色表。短引文：Cherry，“芊悦”“阳光积极、亲切自然小姐姐（女性）”；支持 qwen3-tts-flash，支持普通话与英语等语种。

已核得足够编写一次性素材调用的官方契约；本次到此收敛。接下来由主控在已有授权范围内运行，实际成功与质量须以保留的图片、音频及响应证据判定。

本轮执行补充

本轮执行器直接使用生成服务返回的原始媒体 URL，并将其与下载文件 SHA-256 绑定。 未建设统一重新上传步骤，因此不得裁剪/转码本地音频或修改图片后仍提交原始 URL。 如实际 TTS 超过 15 秒、人物不合格或文件超规格，停止本轮后续生成，不自动重试或替换素材。
