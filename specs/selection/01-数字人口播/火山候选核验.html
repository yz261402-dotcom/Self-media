火山引擎 OmniHuman1.5 候选核验

2026-09-21 核验记录8 个章节Markdown 原文

核验日期：2026-09-21（本任务环境日期）。范围：图片与音频驱动的数字人口播接口，以及同输入 15 秒 A/B 试验所需的参数和预算依据。本文不作优胜者判断，也不决定项目技术栈。

1. 证据边界

  • 官网文档已核验：OmniHuman1.5 的生成接口正文、产品规格、公开价格、并发、任务状态、签名公共参数和服务条款。文档中的“高质量”“自然”等描述只代表厂商声明，不是本项目的质量证据。[S1][S2][S3][S4][S5]
  • 账号未实测：用户已说明两家数字人接口已开通；这是用户提供的信息。本次没有读取账号、余额、密钥、控制台价格或配额，没有完成实际鉴权与连通性验证。
  • 质量未实测：没有提交任何生成任务，没有付费调用，没有查看、下载或播放示例媒体，也没有以官网案例或项目既有 demo 作为效果证据。本项目的人像和音频仍需准备后再做 A/B。
  • 取证方式：使用 agent-reach 的 Exa 搜索定位第一方 URL，以 Exa 提取页面元信息；正文主要通过 Jina Reader 读取火山官网页面。部分页面首次只返回导航或空正文，使用新文档域名及延长页面加载时间后取得正文。原始 HTML 曾读到接口字段但未以不完整片段替代全文。浏览器直接访问出现 ERR_CONNECTION_CLOSED，不作为页面不存在的证据。
  • 版本区分：当前导航入口为 OmniHuman1.5。[S1][S2] 旧研究 URL https://www.volcengine.com/docs/85621/1810471 重定向名称为 DigitalHumanQuickMode-CallStep2VideoGeneration，本轮不沿用其旧版字段。

2. 可以据此实现的 API 契约

以下除特别标注外均来自现行“调用步骤3：视频生成”正文。[S1]

2.1 入口、方法与鉴权

  • 服务地址：https://visual.volcengineapi.com。
  • 提交和查询都用 POST，Content-Type: application/json。查询动作名字含 Get 不表示 HTTP GET。
  • 提交 Query：Action=CVSubmitTask&Version=2022-08-31。
  • 查询 Query：Action=CVGetResult&Version=2022-08-31。
  • 签名固定 Region=cn-north-1、Service=cv。短原文：“本服务固定值：Region为cn-north-1，Service为cv”。
  • 使用 AK/SK 的 HMAC-SHA256 签名；Header 中包括 UTC X-Date 和 Authorization；临时凭证另带 X-Security-Token。签名公共规则来自接口直接引用的官方公共参数页，不能改成普通 Bearer token。[S4]
  • Authorization 格式为 HMAC-SHA256 Credential={AccessKeyId}/{ShortDate}/{Region}/{Service}/request, SignedHeaders={SignedHeaders}, Signature={Signature}。Action、Version 放 Query，业务字段放 JSON Body。[S4]
  • HTTP API 入口已确定。主体识别/检测页指向官方 SDK使用说明 和 HTTP请求示例。快速入门说明 SDK 封装签名和 API 调用，支持 Python、Golang、PHP 等；本轮没有进一步核验具体包版本与 OmniHuman1.5 的封装方法。[S6][S7]

2.2 提交请求

必填字段：

  • req_key: string，固定 jimeng_realman_avatar_picture_omni_v15。
  • image_url: string，人像图片 URL。
  • audio_url: string，音频 URL。

可选字段：

  • mask_url: array<string>：需要指定某个或多个主体讲话时，传“步骤2：主体检测”产生的相应 mask URL；普通单人试验可先不传。[S1][S2]
  • seed: int：默认 -1，即随机。官方措辞为相同正整数 seed 且其他参数一致时“极大概率效果一致”，不保证位级复现，也不表示请求幂等。
  • prompt: string：支持中文、英语、日语、韩语、墨西哥语、印尼语，按官网原文保留语言名称。接口页说“建议长度≤300字符”，产品页说“不可超过300字符”；试验约束取不超过 300 字符。[S1][S2]
  • output_resolution: int：720 或 1080，默认 1080。
  • pe_fast_mode: bool：默认 false。开启会牺牲部分效果以加速。官方为接近即梦客户端效果而建议 720 + true、1080 + false；这是模式建议，不是两个字段必须如此组合的硬性校验规则。

用于准备同输入试验的明确配置示例（不是已执行请求）：

POST https://visual.volcengineapi.com?Action=CVSubmitTask&Version=2022-08-31
Content-Type: application/json

{
  "req_key": "jimeng_realman_avatar_picture_omni_v15",
  "image_url": "<本项目新准备且可读取的图片URL>",
  "audio_url": "<本项目新准备的15秒音频URL>",
  "seed": 20260921,
  "output_resolution": 1080,
  "pe_fast_mode": false
}

上述 seed 只是项目的固定记录值，并非跨模型可比的随机状态。1080/false 是保留默认质量模式的试验建议；如果统一 A/B 选择 720P，应同时明确记录是否开启快速模式，不能把分辨率和模式差异误判为厂商差异。

提交成功示例的业务码为 10000，任务 ID 在 data.task_id。[S1] 此时只说明受理成功，不能认定视频成功或素材合法性检查全部完成。

2.3 查询与结果

POST https://visual.volcengineapi.com?Action=CVGetResult&Version=2022-08-31
Content-Type: application/json

{
  "req_key": "jimeng_realman_avatar_picture_omni_v15",
  "task_id": "<提交返回的task_id>"
}
  • 查询必填 req_key、task_id。
  • 可选 req_json 是 JSON 序列化后的字符串，可携带 aigc_meta 隐式标识配置，不是直接嵌套对象。返回可包含 aigc_meta_tagged。
  • data.video_url 是生成视频链接，官方写有效期为 1 小时。
  • data.status：processing 为前置处理，in_queue 为已提交，generating 为处理中，done 表示处理完成但可能成功或失败，not_found 表示不存在或已过期，expired 表示已过期。
  • 必须结合外层 code、message 及视频 URL 判断成功，不能只判断 status == done。文档注明任务可能在 12 小时后过期。[S1]
  • 实测需及时保全返回 JSON 和生成视频，记录请求 ID、任务 ID、状态变化与开始/结束时间；这是本项目试验记录要求，不是厂商强制字段。

3. 素材要求与输出

产品页“入参与出参说明”及注意事项提供以下信息。[S2]

  • 图片：支持 JPG(JPEG)、PNG、JFIF 等常见格式，建议 JPG；小于 5 MB，小于 4096×4096。这是官网原文，未明确下限、长宽比边界、大小单位采用 MB 还是 MiB、EXIF 旋转处理方式。准备素材时留出余量。
  • 支持任意画幅的人物或其他主体图片；单张图片结合音频驱动。没有在已取正文中找到“必须正脸”“只允许一个人”等硬性限制。[S1][S2]
  • 官方效果注意事项：“人脸占比过小会偶现口型不动（角色不说话）的现象，尽可能规避超远景”；极端姿势或角度可能效果不佳；人物离开画面再进入容易出现一致性变化。[S2] 因而单人、清晰、正面或轻侧面、完整口部的中近景适合作为首个受控试验输入，这是测试设计建议，不是 API 硬性门槛。
  • 建议先做主体识别；只有需要指定说话主体时才需要主体检测，可不指定主体时跳过主体检测。[S2][S7] 主体识别的 req_key 为 jimeng_realman_avatar_picture_create_role_omni_v15，主体检测为 jimeng_realman_avatar_object_detection，两者均接收 image_url。检测页注明最多检测 5 个主体，mask URL 按主体 mask 面积大小排序，有效期 1 小时。[S7] 此报告未展开辅助接口的完整调用契约，不把三步全部强制为首轮单人试验前置，也不预设辅助接口免费。
  • 音频：时长必须小于 60 秒；官方建议 15 秒以内，超过 15 秒效果可能劣化。过长音频可能提交正常，随后查询报 50215 / Input invalid for this service.。[S1][S2]
  • 尚未查明：音频支持的扩展名/编码、采样率、声道、码率、最大文件体积、静音长度要求。不能把 WAV/MP3 支持视为本轮已获官方确认。
  • URL：接口需要可被服务端读取的 URL。[S1] 未核到强制存储供应商、签名 URL 最短有效期或是否需要公网匿名访问的明确文字。为同输入测试准备的 URL 应保证生成期间有效，但具体托管方式留到实现时确认。
  • 输出：MP4，1080P 或 720P。[S2] 已核正文未明确帧率、视频编码、精确像素长宽、竖屏长短边定义、输出时长误差与是否原样保留输入音轨，需实际读取输出媒体信息核验。
  • 产品页声明 1080P 的 RTF 为 27、720P 为 23，并提示服务堆积可能增加耗时。[S2] 按 15 秒音频推算约 405 秒 / 345 秒仅是该指标的算术估计，不是延时承诺，也不是实测结果。

4. 并发、轮询、取消及幂等

  • OmniHuman1.5 产品页公开并发限额为 1。[S2] 账号当前配额未读取。
  • 生成接口列出 429 / 50429（QPS 超限）和 429 / 50430（并发超限）；文档把两类都列为可重试，但没有给出已核实的具体 QPS 数字。[S1]
  • 没有在已核正文找到推荐轮询间隔、Retry-After 规则或 Webhook 回调契约。试验执行器可自行采用约 10 秒间隔、有限总时长的串行轮询，并保存每次响应；必须标注这是项目策略。
  • 没有找到取消端点、取消状态、取消收费或幂等 token 的明确文档。未知不等于不支持。seed 不是幂等键；同参数重复提交可能生成多个任务。
  • 首轮建议每个候选只提交一次；提交超时但不能确定是否受理时，不自动重发。官方标“可重试”也不自动构成本项目增加付费尝试的授权。

5. 公开计费与 15 秒试验预算输入

OmniHuman1.5 自身产品页写明：“本服务按生成视频时长计费”，单价 1 元/秒、并发 1。[S2]

视频计费总页写明：“只有调用成功（正常返回生成的视频），才会进行计费”，以及“最新价格信息，以控制台实际接入为准”。[S3] 总页价格表的相关行仍叫“数字人快速模式”，而非逐字标为 OmniHuman1.5；1.5 的单价依据应引用它自身的产品页，总页用来说明通用成功计费原则。不能因旧名称就另行推定新型号折扣。

  • 一次恰好 15 秒、按 1 元/秒成功生成的名义费用：15 × 1 = 15 元。
  • 两次该候选各 15 秒的名义费用：30 元。首轮只需一次时不要自动增加第二次。
  • 这不是账单级硬上限：输出时长取整、最小计费粒度、720P/1080P差异价、账户协议价、税费处理、辅助识别/检测接口费用和存储流量尚未全部核清。
  • 公开文档没有提供本账号的余额、赠送额度、资源包或优惠证据，本轮均不使用这些假设压低预算。
  • 在真正提交前，将控制台该模型实际价格与本轮允许的总金额对应上；还需把新素材生成成本、TTS 成本和另一候选成本加入整个 A/B 预算。本文的 15 元只涵盖这一候选的视频生成名义费用。

6. 开通及素材权利

  • 用户已确认接口已开通，但本项目未验证具体模型权限、AK/SK 权限或计费状态。
  • 官方快速入门文字说明：登录并实名认证 → 进入智能视觉控制台 → 选择相应服务的“开通服务” → 根据界面选择免费试用或正式调用并确认 → 获取 AK/SK 后调用已开通的能力。[S6] “概览 → 服务管理”可查看已开通服务，“系统管理 → 用量统计”可查调用量、QPS/并发、错误量与耗时。该通用页面列出试用选项，不保证 OmniHuman1.5 对当前账号一定有免费额度。
  • 即梦AI服务专用条款发布、生效日期均为 2025-04-17。第 3.4 条要求客户上传和处理的图片、音频等内容的知识产权归自身或“已获得权利人合法授权”，并且未侵犯他人权利。[S5] 用于本项目的人像、声音应保留权利来源；不能因素材能被 URL 访问就认为可用。
  • 第 3.5 条说明生成内容由用户自行在合法合规范围内维护和使用，生成内容可能不独特；该条不是对所有输入及输出的全面商用免责保证。[S5]
  • 第 3.3.4 条要求集成即梦AI服务的面向最终用户应用界面突出显示“由即梦AI提供技术支持”并链接到即梦站点；第 3.9 条禁止删除、篡改、隐匿深度合成服务标识；第 3.11 条涉及传播非真实音视频时显著标识。[S5] 这些是若后续产品集成时需要核对的具体条款，不是本轮多加的审批流程。
  • API 的隐式标识配置与上述条款相关，但文档返回 aigc_meta_tagged 不等于整个产品已完成所有标识义务。[S1][S5]

7. 留给同输入 A/B 的确定项与未知项

可以先确定的输入基线：新准备一张清晰、单主体 JPG，严格小于 5 MB 且宽高留在 4096 像素以下；使用同一个最终时长不超过 15 秒的中文口播音频；两家共用图片、音频内容与可读取 URL，保存文件摘要和媒体参数。选择 1080P 时，此候选显式设置 output_resolution=1080、pe_fast_mode=false，首轮只提交一次。[S1][S2]

实测前仍需落定：音频文件编码是否获官方支持确认；素材 URL 的读取和有效期；两家共同输出档位；本账号实际单价；新图片与语音的获取方式和成本；整个试验预算。实测后才能判断中文口型、身份保持、面部/牙齿异常、肢体稳定、画面裁切、音轨质量、完成耗时、成功率与账单。
