# 剧本展示与审核恢复

用户确认：生成的剧本先显示并可编辑；采用与下一步仍需审核通过，不新增人工跳过审核。

已定位问题：后端投影和前端均隐藏未全部通过的候选；未审稿进入返工目标；审核未知状态缺少绑定当前批次、明确计费确认的恢复入口。

## 实现计划

- [x] 后端展示已落库的当前候选，写稿成功后、审核前绑定当前批次；未审和失效稿列为审核目标，明确质量失败稿列为返工目标。保持采用规则。
- [x] 前端展示候选与审核状态，保留编辑入口；待审稿显示重新审核，明确失败稿显示按意见重写。待审批次不触发补写或重写。
- [x] 重新审核支持当前批次未知审核调用的显式计费确认；新意图与旧记录分开，同一请求幂等回放，不调用写稿模型。过期、跨作品、错误阶段与有远端句柄的目标拒绝。
- [x] 先编写和运行失败测试，再实现；后端使用独立测试 schema，前端使用现有组件和 store 测试。测试与验证不进行付费调用。
- [x] 独立审查、相关回归、前端类型与构建检查通过后重启后端，读取当前作品确认三篇初稿可见，原未知记录和费用预留仍保留。

## 验收

审核中、审核失败或超时时，已经生成的三篇分镜保持可读、可编辑；未审稿不能采用，页面能明确进入重新审核。未审稿不会因点击批次恢复入口被提交返工。审核重试必须由用户确认可能重复计费，旧未知请求不被重发、清除或结算为零。

## 审核反复失败与耗时的追加修复

用户补充审核反复失败且返工耗时。已定位分镜制作计时误入事实覆盖检查、日常剧情结束语误入时效检查；审核输入同时发送派生正文与完整分镜，且未携带用户指定的镜头数与时长要求。

- 修正制作计时及日常剧情结束语误判，保留现实价格、新闻、数据、发布事实等核验。
- 当前历史分镜仅重算两个确定性检查的读投影和采用门禁，不修改原候选、历史质量报告或费用记录。
- 分镜原文与结构化字段确为同一内容时只发送一份；正文有额外内容则完整保留。参考、资料、风格和创作要求不截断。
- 写稿、返工、审核共用生成能力约束；问题清单只列明确失败原因、合并同类问题，每稿最多三条。可读性建议不额外否决。
- 本机关闭自动返工（MAX_REPAIR_ROUNDS=0）；一次审核后用户决定编辑或定向修改。审核可等待300秒、输出上限4096，均不触发自动重发。
- 重新审核同时重新评估失败稿；仅通过稿不重复单稿审核，集合始终审核当前三篇。

上述改动仅能减少重复输入、自动调用及已知规则误判；不声称真实模型速度或最终通过率已提升，真实审核仍由用户在页面确认后发起。
