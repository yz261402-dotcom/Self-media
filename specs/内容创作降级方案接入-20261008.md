# 内容创作降级方案接入

日期：2026-10-08。

## 直接内容工作流

内容创作的“直接按主题生成三稿”改为 `POST /api/v1/works/{work_id}/content/direct-generations`，使用现有内容任务调度器和文本供应商，不进入 DeepAgents。

主题、资料、提示与生成任务在一个事务中准备，返回 202 与持久任务回执。旧 `/scripts` 同步接口也改为调用相同业务入口，保留超时原任务编号。直接工作流创建标准主任务，等待人工选择；内容任务提供生成进度，重启时不会将等待选稿的主任务交回 DeepAgents。

原稿及费用台账保留。同一请求编号精确重放原结果；首次准备提示推进创作修订号后，丢失响应的客户端仍保存原完整请求，显示“核对原生成任务”。未确认的模型请求阻止新的直接收费提交。

## 人工创作

在短视频分镜路线增加“导入 / 手写分镜”。支持结构化镜头编辑和 JSON 对象 / 数组导入，可增删排序镜头。用户填写接管原因并明确确认人工接管与内容核对。

保存为独立单篇人工批次，来源为 `manual`，智能体审核状态为 `not_performed`。不可变审计记录绑定稿件、批次、创作输入、修订号和人工确认。完整结构、镜头编号、2–30 秒整数时长、镜头上限及目标总时长仍需校验。

保存后进入已有人工评分页，全部评分完成且平均分严格大于 4 才确认采用，记录采用依据 `manual_takeover`。不合格时可以手改后确认采用，修改稿需重新核对内容；不会伪造模型通过。已采用的单篇人工稿可以进入视频制作。

人工接管保留未知模型作业和费用记录，不取消已发送的外部请求。若旧主任务仍有 DeepAgents 委派，事务内停止旧主任务并切换到新的人工审核主任务，旧委派无法继续提交写稿或覆盖人工稿。写稿工具的活跃检查与内容任务预留也共用事务锁，覆盖接管与工具提交之间的竞态。

人工导入稿没有原来的模型三稿批次，因此返回模型写稿时从内容创作直接生成新稿，不提交无法执行的原地返工。若原模型请求未确认，需先核对才能新增收费请求。

## 故障隔离

写稿模型配置异常时仍能读取内容状态、创作修订号和人工入口。审核配置异常时保留原稿展示，但关闭模型采用资格。人工来源的展示、评分和采用不需要加载写稿或审核模型配置。

此次处理的是编排与文本模型的降级；前端、FastAPI 和业务数据库仍需正常运行。算力云隧道保持关闭。
