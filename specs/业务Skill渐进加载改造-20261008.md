# 业务 Skill 渐进加载改造

用户已确认：补齐标准元数据、统一实际调用规则、按需加载正文与参考文件。

## 设计

- 保留业务编号 S01/S02/S03；目录分别为 topic-planning、content-writing、content-review。
- YAML 包含 name、description，以及字符串 metadata.skill_id、metadata.version。
- S02/S03 将口播和分镜差异放入各自的 references/talking-script.md、references/storyboard.md。
- 公共库负责元数据校验、受限读取、虚拟文件快照及含参考文件的摘要；不依赖 DeepAgents，降级创作可独立使用。
- DeepAgents 只先展示角色白名单中的 Skill 元数据，通过 read_file 读取受控内存文件；不开放真实磁盘或写入工具。
- 实际文本消息按阶段加载 S01（策划）、S02（写稿/返工）、S03（审核），只读取当前内容路线的参考规则。JSON 输出契约及后端硬门禁继续由代码维护。
- 修正旧模型供应商、必须整组三稿通过才展示等过时规则；人工评分只用于现有分镜路线。
- 配置错误在模型请求前明确阻断；不增加模型调用轮次，不自动重试未确认的付费请求。
