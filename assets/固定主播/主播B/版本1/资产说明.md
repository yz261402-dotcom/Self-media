# 固定主播 B · 版本 1

用户在本会话明确选择“人物B+音色3”。本目录登记人物 B 与 MiniMax“温暖闺蜜”的原始素材及固定参数。

- `基础人物.png`：941×1672 的主参考图，身份 ID `av_base_b_v1`。
- `音色3-温暖闺蜜试听.wav`：原始基准音频；声音 ID `voice_minimax_warm_bestie_v1`。
- `人物原始提示词.txt`：本项目生成图片时使用的提示词。
- `角色档案.json`：身份、声音参数、来源、选择审批及待验收项。
- `校验摘要.json`：原始文件和角色档案的 SHA-256，路径相对工作区根目录。

原件在 `experiments/人物与音色选型/AV-001` 中保留，副本与原件内容一致。修改身份、声音或主参考图需创建新版本，不覆盖本版本。文件当前为 integration 选型资产，尚未通过生产验收；不存在已部署的资产数据库或自动生产保护逻辑。
