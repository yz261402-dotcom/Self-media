# S02 内容写作

版本：0.3.0 · 使用者：写作智能体（content）· 验证范围：离线契约

## 1. 触发条件
用户选择口播稿或短视频分镜路线，输入主题或确认参考写作提示后，需要产出三个不同角度的原创候选。

## 2. 输入引用
`Work.brief.content_route`、主题、目标时长、Redfox 参考快照、已确认写作提示、账号风格和可核验资料。

## 3. 工作步骤
1. 整理参考的表达手法与叙事节奏，不复制原句、不做同义词替换式改写。参考视频默认是灵感，不作为已核实事实。
2. 由 Claude 写三个角度互异的候选，slot 为 1、2、3；标题、简介和实际内容一致。
3. 口播稿使用适合朗读的自然短句，不强制提问开头，不在正文中混入控制标记。
4. 分镜路线使用结构化 `storyboard`：连续镜头编号、画面、台词或旁白、音效、2-30 秒整数时长、Wan 画面与声音提示词。跨镜头通过叙事和场景切换衔接，不假定独立生成片段动作连续。
5. 事实断言绑定资料 ID、精确来源摘录和正文位置；缺少资料支撑时删除断言或使用明确的观点与归因。
6. 返工只重写被审核指出的候选，保存新版本和旧版本关系，再由独立 Qwen 审核；写作智能体不能批准自己的稿件。

## 4. 允许调用的工具
`register_script_candidates`、`propose_memory`。不调用配音、数字人、拼接或发布工具。

## 5. 输出契约
候选包含 `content_route/angle/title/description/tags/text/duration_estimate_ms/claims`；分镜稿另外包含完整 `storyboard`。
写稿工作项返回 `batch_id` 引用；只有当前三个候选及整组审核全部通过，业务层才对用户展示正文。

## 6. 拒收 / 返工条件
- 论文腔、书面长句、与标题不符的正文 → 返工。
- 捏造事实或无法定位来源的数字 → 拒收（硬门禁）。
- 表达标记污染正文、不足三个角度 → 拒收。

## 7. 正反例
正例："开头 3 秒抛问题，15 秒给结论，再用一个具体例子解释，收尾给一句可执行建议"。
反例："正文中出现 `[emotion:excited]`、`00:12-00:15` 这类控制标记"。
