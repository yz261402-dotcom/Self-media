# 分镜写作

用于 `content_route=short_video_storyboard` 的初稿和明确发起的定向重写。产物是可逐镜头投喂生图与 Wan 图生视频的结构化剧本。

## 镜头与人物

- 每个镜头对应一个独立生成片段，给出清楚首帧和一项主要动作。不要在单镜头塞多个场景硬切、反复状态变化或不可能的机位关系；跨镜用叙事和场景衔接，不假定独立片段动作无缝连续。
- `shot_index` 从 1 连续递增；`duration_seconds` 为 2 到 30 的整数，对白长度匹配时长。镜头数、总时长及指定剧情以创作要求为准；无另行目标时，参考路线总时长接近源视频时长。
- 已绑定数字人物时，每镜以该人物为主角，保持面部、发型、年龄感、身材比例和身份一致。服装以已选人物参考图为基准，颜色、款式、层次、材质、图案与配饰跨镜一致；不自行换装、变色或增减外套与配饰。未提供服装细节时不逐镜另造，参考视频服装不能覆盖人物基准。
- 同一场景的布局、道具和状态保持连续；明确发生场景切换或动作导致状态变化时才调整。允许改变动作、表情、机位和构图，不能把切换解释成换人。
- 参考画面观察仅为灵感。描述原视频时，动作与时段来自已有 `visual.scenes`，不扩大低置信度或采样间隙观察；无有效口播时不编造原视频台词。原创剧本可以设计新动作，须与参考观察区分。

## 声画制作

每镜完整提供画面、对白或旁白、音效或环境声、时长及给 Wan 的画面与声音提示，声画含义一致。声音由 Wan 原生生成，无需用户音频；不把独立配音、口型同步或未提供的屏幕跟踪合成设为必需步骤。用画面和对白表达笑点，不依赖模型精确生成大段中文界面。

制作计时和虚构角色的日常话语不等于现实新闻事实；现实价格、发布时间、数据和机构结论仍需证据，按入口规则附 `claims`。

## 输出契约

初稿仅输出：

```json
{
  "candidates": [
    {
      "slot": 1,
      "angle": "角度名",
      "title": "标题",
      "description": "一句话说明",
      "tags": [],
      "storyboard": [
        {
          "shot_index": 1,
          "visual": "首帧画面与主要动作",
          "dialogue": "台词或旁白",
          "sound_effects": "音效或环境声",
          "duration_seconds": 8,
          "prompt": "人物、服装、场景、动作、机位和声音提示"
        }
      ],
      "claims": []
    }
  ]
}
```

初稿包含 slot 1、2、3 三篇，镜头示例按实际剧情扩展；无对白或音效时相应字段可为空字符串，不能省略。定向重写只输出指定 slot 的完整 `storyboard/claims/repair_note`，不能用局部镜头片段代替完整新版本。

写稿后的模型审核关注证据、创作要求和实际可制作性；主观吸引力交由人工评分表判断。审核失败时保留草稿供编辑或重审，不自行发起返工或伪造人工通过。人工流程见 S03 对应分镜审核参考。
