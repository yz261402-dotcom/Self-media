# S01 选题与新意

版本：0.2.0 · 使用者：策划文案（content）· 状态：拟建，未验收

## 1. 触发条件
作品已有 `brief`（内容/选题、受众、关键词、目标时长），需要形成选题依据与切入角度时。

## 2. 输入引用
`Work.brief` 中用户提示词、关键词、受众、时长与可选用户资料；若为返工，再读取质量角色给出的内部查重报告。资料可空，不以联网为前置。
不读取 demo 目录或任何历史失败工程的文件。

## 3. 工作步骤
1. 明确受众与栏目定位，列出本期要回答的一个具体问题。
2. 直接根据用户提示和已有知识提出切入点，不调用网络搜索、网页抓取或浏览器工具。
3. 先生成相互不同的角度；若收到质量角色的历史重复反馈，再调整问题、案例或论证路径。
4. 输出 3 个候选角度，每个角度必须对应不同的问题或论证路径。
5. 涉及无法核对的关键事实、最新版本/价格或数字时标记待复核，不凭模型记忆编造来源、链接或热度。

## 4. 允许调用的工具
`register_script_candidates`、`propose_memory`

## 5. 输出契约
S01/S02 可在同一写稿工作项加载，`AgentResult.output_refs` 至少含稿件批次 ID；`objective` 说明本期问题。
角度描述写入候选稿的 `angle` 字段。

## 6. 拒收 / 返工条件
- 三个角度只是同一观点的同义改写 → 返工。
- 出现无来源的数据、价格、版本或收益承诺 → 拒收并标为硬门禁失败。
- 只有模型自审却仍声明"已核实" → 拒收。

## 7. 正反例
正例："同一个 RAG 话题，分别问『为什么企业落地失败』『它和微调怎么选』『成本到底花在哪』"。
反例："三个角度都是『RAG 很重要，能提升效果』的换标题复述"。
