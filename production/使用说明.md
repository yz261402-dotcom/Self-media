# 工作台使用说明

先打开工作台，点击顶部“新建作品”，然后按制作顺序操作：**创建作品 → 确认人物 → 三选一稿件 → 试听与确认 → 合成与下载 → 抖音发布**。每页先展示当前操作；技术记录与完整检查结果可以展开查看。左侧七个入口保留；发布页已接入首版抖音浏览器 Adapter，指标监控和领域模型选择仍为开发中。

短视频分镜路线在“内容创作”切换，流程为：**创建作品 → 三选一审核通过的分镜 → 确认图片预算并生成镜头图 → 看图并确认 Wan 费用 → 逐镜头生成 → 审核原片 → 本地拼接 → 确认成片并进入发布**。这条路线不要求人物和外部配音。

## 一、打开工作台

在项目根目录的 PowerShell 中执行：

```powershell
.\production\start.ps1
```

默认入口：<http://127.0.0.1:5173>。后端健康检查：<http://127.0.0.1:8000/api/v1/health>。

脚本复用已运行服务，并核对本地分镜拼接 Worker 的 PID 与命令行后复用或启动。若修改了后端代码或 `.env`，需要重启对应后端和本地 Worker 才能生效；刷新网页只能刷新前端。日志与 PID 文件在 `production/runtime/`，拼接异常查看 `storyboard-worker.err.log`。不要根据旧 PID 直接结束进程，先核对该进程是否仍是本项目服务。

GPU 连接完成一次性[长期隧道配置](隧道使用说明.md)后，由 Windows 登录任务自动维持。`start.ps1` 会启动守护程序并检查四阶段 Worker；连接异常会明确提示。仅使用文案或发布既有成品时可加 `-SkipGpuTunnel`。SSH 自动重连不等于云端 Worker 自动启动。

云端 Worker 可另做一次[恢复服务安装](Worker运维说明.md)。安装完成后，`start.ps1` 会先检查并确保 Worker 存在，再检查隧道；实例重启后下次启动项目即可恢复，无须手工进入算力云重新输入 Worker Token。

首次部署缺少依赖时才执行以下安装步骤。已有 `.venv` 和 `node_modules` 时可以直接启动：

```powershell
python -m venv production/backend/.venv
.\production\backend\.venv\Scripts\python.exe -m pip install -r production/backend/requirements.lock.txt
npm --prefix production/frontend ci
```

当前后端环境使用 Python 3.13；前端需要 Node.js。后期还需要带字幕滤镜的 FFmpeg，且同目录有 `ffprobe`。可在后端配置 `AVATAR_STUDIO_FFMPEG_BIN` 指向其 `bin` 目录。

首次使用抖音发布时，确认本机已安装 Google Chrome，另外安装发布依赖：

```powershell
.\production\backend\.venv\Scripts\python.exe -m pip install -r production/backend/requirements-publish.txt
```

安装后重启本项目后端。发布已有交付包只需本机服务与网络可用，不占用 GPU，也无需为此启动算力云。发布登录使用专用 Chrome 窗口；不要复制日常浏览器 Cookie，不要分享 `production/backend/runtime/publish/douyin-profile/` 中的登录资料。

模型密钥与 Worker 地址由服务端 `production/backend/.env` 管理，不在前端填写。已有配置不要重新覆盖。“领域模型选择”仍是开发中入口。

## 二、第一次做一条视频

### 第 1 步：创建作品

点击“新建作品”，填写本期主题、目标受众、时长和补充要求。例如：

目标时长为选填，留空按内容自然展开；填写时接受正数秒，不再限制为 45–90 秒，也不默认要求 60 秒。目标只指导写稿，实际视频时长取自用户确认的全文音频。模型单次请求窗口、文件大小、内存、磁盘与执行超时仍属于运行条件，不能据此承诺任意长视频一次生成成功。

字幕支持长音频：超过 180 秒时按低能量边界分段识别，通过真实识别文本匹配冻结稿，逐段对齐后按采样偏移恢复全局时间轴。匹配不了时报告具体错误，不按字数均分时间。2026-09-26 已用既有音频重复五遍构成 232.142 秒测试输入并跑通；该测试证明长字幕处理，不等于完成同长度数字人口播的效果验收。

> 给刚接触 AI 的大学生解释 RAG，约 60 秒。开头用“为什么 AI 读了资料还会答错”引出问题，用生活例子解释，不夸大效果。

创建后确认顶部显示的是这期作品。历史作品可以重新打开；相同标题可能对应不同作品，可用日期和 ID 后缀区分。

### 第 2 步：确认人物

打开“人物形象”，找到标记“已确认，可以制作”的主播，点击“使用这位主播”。此前选择的人物 B 仍在人物库内，实际能否进入制作以当前审核和文件状态为准。

若显示资料待完善，点击“完善人物”或“查看待完善资料”。审核区默认打开当前需要完成的一步：

1. 看清原图，登记身份审核结论。
2. 声明参考依据；只有一张图时可选择单原片口径，但必须阅读并确认该口径的限制，不能假称已有多角度验证。
3. 填写素材来源与使用范围，确认权属依据。
4. 点击“确认并定版”，保存为固定人物，然后选用于当前作品。

已冻结的旧人物不能原地覆盖。如果旧审核留痕不足，使用“复制为新草稿”，在同一真实原图基础上重新完善四步。旧人物、旧作品和原资产会保留；复制不会自动替你通过审核，也不会自动获得全部动作和变体资产。

“新建主播”可以按性别、年龄、外貌和自由描述调用图片模型，生成的是待审候选，可能收费。已有满意人物时无需反复生图。

M2 还需要以下素材：

- **已审人物变体**：作为动作底片源图。换背景需确认过的蒙版和已登记背景；原始人物主图不能直接冒充变体。
- **动作参考**：展开“动作参考”。已有动作可直接选择并点“使用这个动作”；新人物没有动作时，点“从已有动作添加”，选择模板、播放参考视频，确认后点“添加并使用此动作”。出现“本期动作”表示已保存，完成配音后再到视频页生成动作底片。添加动作只复用项目素材，不调用模型或产生生成费用。

目前项目动作库有一段约 15.24 秒的“自然讲述·微笑基调”，只提供表情与头部动作。预览中的人物是动作来源，最终主播仍由当前人物图片决定；该实验参考有循环接缝，长视频可能出现动作重复。动作模板与人物外貌分别管理，新草稿不会自动继承人物身份审核。文件缺失、变化或来源状态不再有效时，页面会显示具体原因。

**自定义动作**：点击“上传自定义动作”，选择 3–60 秒、100 MiB 以内的 MP4/MOV，点击“上传并检查”。传输进度到 100% 后还要等待检查完成；系统保留原文件，将参考转成最长边不超过 1280、25fps 的无声 H.264 视频。不会把参考视频里的声音用于口播。

出现预览后，实际播放视频，填写模板名称、动作分类与视频来源，勾选确认，再点击“保存并用于本期”。分类只是方便查找，具体动作由视频内容决定。建议使用正面、单人、面部清晰的录制，做自然眨眼、微笑、小幅点头或转头。只有技术检查通过不代表动作效果已通过，生成底片后仍须观看。

上传完成但未确认的记录会显示“待确认”，刷新后可继续完善。已保存模板可点“用于本期”，也可在已有动作库中复用给其他人物。录制的短动作会循环至配音所需长度，循环接缝需人工查看。当前不支持自由生成挥手等全身动作。

本机上传和保存不会调用模型。生成底片时，已登记图片、动作、底片和音频才通过鉴权通道传给算力云 Worker v2；不发布为公网素材。连接失败或 Worker 太旧会给出错误，不会提交一个无法读取本地文件的作业。

当前 M2 主要迁移表情、眼睑和头姿，再驱动口型，不支持按任意文字设计全身动作。换衣的图像编辑一致性也尚未通过项目验收，不能把新生成的不同人物自动认作原人物。

### 第 3 步：生成并采用稿件

打开“口播稿”，填写“这期讲什么”，点击“生成三稿”。有事实资料时展开“补充参考资料”。

系统依据提示词及用户提供的材料写稿，不联网搜索。等待生成和质量评估，比较三个候选的角度、全文和审核原因，点击一篇的“采用这篇”。质量通过只是允许采用，不会替你选稿。

硬门禁失败的稿件不能进入 TTS。可点“让模型重写”，也可编辑后“保存并重审”。缺少事实来源时补充材料；本阶段无法靠联网替你查证最新事实。

点击“下一步：试听配音”。采用后再次改正文会使旧音频、嘴型、字幕与成片失效，这是为了防止画面和声音仍对应旧稿。

### 第 4 步：试听并确认全文音频

打开“语音配音”，在音色列表中选择声音；本项目既有选择是音色 3。先试听短样，再合成全文。详细检测结果默认收起，不影响播放器和确认操作。

试听和全文合成是两次不同用途的请求，都可能收费。若完全相同输入已有有效全文音频，普通合成优先复用。明确想重做时使用“重新合成（可能再次收费）”。

用播放器听完全文，核对发音、语速、停顿、情绪和内容，勾选听检确认，点击“确认这条全文音频”。视频会沿用这条音轨。仅生成试听或仅选音色，都不等于完成此步。

占位音频、文件缺失或未通过检查的音频不能确认为最终音频。确认成功后点击“下一步：合成视频”。

### 第 5 步：生成口播，制作成片并下载

本页按三个阶段操作。

**A. 生成口播原片**

1. 先看“生成前需要完成”，按直达按钮处理人物、稿件、音频或素材缺项。
2. 默认使用 M2；需要身体动作时可选择云端 OmniHuman。云路线需要费用提示确认，动作效果仍需生成后审核。
3. M2 如未有合格动态底片，先展开“准备动作底片”，选择已审人物画面，生成底片并观看，登记身份是否漂移。底片时长需匹配当前全文音频。
4. 查看本次模型、时长、调用清单和金额并确认。服务端还会独立检查预算，确认报价不会自动提高预算。
5. “检查生成条件（不生成视频）”只做预检。真正出片需点击真实生成按钮，等待 Worker 或供应商完成；刷新状态不会替你创建新作业。

M2 的处理顺序是“人物变体 + 动作参考 → LivePortrait 底片；底片 + 已确认音频 → MuseTalk 口播原片”。OmniHuman 是“同一人物图片 + 已确认音频 → 云端口播原片”。

**B. 观看、审核并确认原片**

用原片播放器检查口型、身份、表情及身体/手部穿帮。点击“观看后审核这条原片”，填写并登记实际结论，再完成音轨检查。系统没有已经验收的视频理解模型代替你判断这些主观项。

通过后勾选观看确认，点击“确认这条为最终原片”。动态底片、Mock 产物和只有生成成功状态但未审的原片，都不能直接进入交付。

**C. 生成字幕与成片**

Wan 分镜路线：镜头拼接完成后，在成片播放器下勾选“确认使用云端 GPU 生成字幕”，点击“生成字幕与成片”。已确认或打包的成片也可补字幕。系统识别视频里实际说出的对白并对齐时间，保留原声与原片；完成后需要观看带字幕新版本，再确认成片并生成新的发布包。新包包含 MP4、ASS/SRT 和封面。生成失败会显示原因并保留原成片，结果未知时先核对原作业。

点击“生成字幕与成片”。代码 Worker 使用真实音频时间轴生成字幕，执行规格统一、清晰度滤镜、响度处理和封面生成，之后技术复验。此步骤需要字幕 Worker 可连接，或有与当前音频及正文完全匹配的有效对齐缓存。

出现成片播放器后，检查字幕是否同步、断句是否合适、声音和画面是否正常。勾选已观看，点击“确认成片并生成下载包”。然后可下载完整作品包，或单独下载视频和封面。

完整包包含 MP4、ASS/SRT 字幕、封面、标题/简介/标签、质量报告和文件校验清单。视频规格为 1080 × 1920、30 fps、H.264 / AAC。可下载后自行投稿，也可进入“发布”页使用首版抖音浏览器发布流程。

### 第 6 步：准备抖音投稿并确认发布

1. 打开左侧“发布”，点击“打开专用浏览器登录”。在新开的 Chrome 窗口扫码登录抖音；若出现验证码或页面验证，由你完成。返回工作台点击“检查登录状态”，以系统实际检测到的账号为准。尚未有成片也可以先登录。
2. 在顶部选择要发布的作品。只有已经观看并确认的真实交付包能开始准备；没有交付包时，先回视频页完成成片确认。核对本页的视频、封面与作品名称。
3. 编辑本次投稿的标题、简介与话题。标题要求 1–30 字，过长需要手动缩短；话题可用空格、逗号或顿号分隔。这些修改不覆盖原交付包。
4. 点击“开始准备（不发布）”。系统在专用浏览器上传视频、填写投稿资料并准备封面，停在最终发布前。出现“等待登录”时完成扫码，再点击“登录后继续准备”；不要重复创建任务。
5. 状态变为“待确认”后，到专用浏览器核对**发布账号、视频、标题、简介、话题、封面和 AI 内容声明**。确认无误后在工作台勾选核对声明，再点击“确认并发布”。这一步才会执行最终发布操作。
6. 查看任务状态。“已提交”不等于平台审核通过或公开可见；请以创作者中心的实际状态为准。“待核验结果”时先检查创作者中心作品列表，系统禁止再次提交，避免重复投稿。

准备期间请保持专用浏览器打开。正在上传时不能取消，需要等准备完成。需要修改投稿文案时，先取消尚未提交的准备任务，修改后重新准备；已经提交或结果未知的任务不能靠取消重建来重复发布。刷新页面会重新读取后端任务，不会自动点击最终发布。

首版只支持抖音单账号、单条作品即时发布。B 站、快手、小红书、微信视频号仍为“开发中”；定时发布、多账号和自动指标监控尚未实现。目前正在进行真实账号的**只上传、不发布**验收，不代表真实发布全链路已验收通过。进展见 [抖音发布实施与验收](../experiments/MVP重构/20260927-抖音发布/实施与验收.md)。

## 三、遇到阻塞时看哪里

- **人物看得到却不能制作**：展开该人物的缺项；“已定版”与全部生产素材齐备是两件事。检查原图文件、审核依据、权属、已审变体及获准动作参考。冻结资料缺失时复制草稿重新审核。
- **稿件生成失败**：查看页面错误代码，检查 DeepSeek 配置、模型 ID 和网络；有稿但不能采用时看具体审核原因。
- **语音没有播放器或不能确认**：确认是全文音频、真实文件存在且检查通过。不要用试听结果代替全文。更换正文后应重新合成。
- **视频一直等待**：看当前任务阶段和错误；先确认算力云已开机、Worker 已启动、地址/令牌有效。SSH 能登录不等于 Worker 可调用。
- **`unknown` / 提交结果未知**：先查询已有作业并对账，不反复创建新任务；上次请求可能已经受理或计费。
- **没有字幕或后期被阻断**：检查 `AVATAR_STUDIO_ASR_PROVIDER=qwen3_cloud`、ASR Worker 地址、FFmpeg/FFprobe 与磁盘空间。系统不会按字数均分来伪造字幕时间轴。
- **“预览版本变化”或旧包失效**：刷新当前作品。确认必须对应刚看到的成片版本；上游变更后重新处理和审核。
- **页面无法打开**：查看 `production/runtime/frontend-5173.err.log`、`backend-8000.err.log`；独立端口对应不同文件名。
- **修改配置后仍是旧结果**：重启本项目后端；启动脚本发现健康服务时只会复用，不会自动替换运行进程。
- **发布浏览器打不开**：确认已安装 Chrome 和 `backend/requirements-publish.txt` 依赖；首次安装后重启后端，再点击“打开专用浏览器登录”。
- **普通浏览器已登录，但工作台仍提示登录**：两者的登录资料不共享。请在工作台打开的专用浏览器扫码，再检查登录状态。
- **发布显示“待核验结果”**：先在创作者中心核对作品是否已经提交，不重复点击、不取消重建。保留任务编号和错误信息供排查。

错误定位时记录作品 ID、任务 ID、阶段、错误代码和时间即可。不要在截图、日志附件或聊天中发送密钥。

## 四、当前能够验收的范围
